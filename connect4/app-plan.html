Overview

Purpose

The purpose of this website is to create a Connect 4 recreation using HTML, JS, and CSS. The game will be local 2 player multiplayer just like if you were playing the real game.

Audience

The main audience is for people who like to play popular table top games looking to have some fun with their friend.

Dynamic elements

In order to have a working game of connect 4, you need to use JS. The elements that will use JS in my project will be:

Board columns - Player selects what column they want to place their piece in

The pieces - Will automatically show up in the approraite place in the column where the user selected

Array - I will use a array to keep track the state of the board

Detect win state - Script will constantly check for if their is a win condition on the board

Psuedocode

Player one's turn first, alternate variable between 1 and -1 to determine whos turn it is.

Board is a 7 by 6 grid. Each Column is able to detect a click. When user clicks column, get index for what column, and search the board array for that index. Each index returns in order what pieces are in that column, and it will find the next open space to place the piece. Whatever coordinate is returned, the color is changed to the players color.

After every move, the script will look for a win condition. this will be a function that will return true if the users last move created a win condition. To start, the program will use the users last move as the starting point. The program will then check each axis for if theres any pieces in succession and add 1 to the counter. If counter reaches four that means there was 4 in a row on that axis so that player won.

If function returns false, that means no one has won, so we multiple the turn variable by -1 to make it the other players turn.

If the reset button is clicked, reset array back to all 0's.
